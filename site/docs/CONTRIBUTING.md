# Contributing

**Contributions are closed until the verified release.**

Joulvo Gym (formerly Kinetiq Gym) is being built and tested as a physical prototype now. V1's CAD, build files and software are
released together once the prototype has passed load testing. Until then there is no tested design to contribute to, so this
repository does not take pull requests, design proposals or build reports.

## What you can do now

- **Follow the build:** join the build list at [joulvo.com](https://joulvo.com/#join) for prototype results, design
  changes and the release date. It is also the kit waitlist.
- **Support the project:** contributions to prototype iterations and build support are in the
  [Support section](https://joulvo.com/#support) of joulvo.com.
- **Engineering work:** for custom mechatronics, motor-control or prototyping projects, use the
  [project form](https://joulvo.com/work).

## After the verified release

Contributions open with the release: build reports, fixes, adaptations (other motors, batteries, mounts), documentation and
software. This file will then describe how to propose a change and how changes are reviewed. Every change is reviewed by the
maintainer before it reaches `main`.

name and logo, and the earlier Kinetiq name and logo, are not part of those licences.
